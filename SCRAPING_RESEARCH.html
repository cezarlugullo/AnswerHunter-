Brainly Brasil — API GraphQL

✓ Endpoint Confirmado ✓ question(id) sem auth ⚠ questionSearch requer token

✓ Endpoint Principal (Confirmado via testes diretos)

POST https://brainly.com.br/graphql/pt

Retorna dados completos de questões e respostas sem autenticação para a query question(id).

EndpointSchemaAuth necessáriaStatus
POST /graphql/ptConteúdo educacional (questões, respostas)Não (para question by ID)✓ Funciona
POST /api/graphqlPagamentos e autenticaçãoSim⚠ Schema diferente

⚠ Sobre a versão do endpoint

O endpoint /api/28/graphql mencionado em fontes antigas não existe. O endpoint correto e atual é /graphql/pt (sem número de versão). O sufixo /pt é o locale português.

Queries GraphQL — Prontas para uso

✓ Testadas e funcionais

Formato do ID (CRÍTICO)

🔑 IDs no formato Relay Base64

O Brainly usa o padrão Relay GraphQL onde IDs são base64(tipo:numericId) com o tipo em letras minúsculas. Maiúsculas causam erro could not parse ID.

Encoding de IDs — exemplos
# CORRETO: tipo em minúsculas base64("question:57830221") = "cXVlc3Rpb246NTc4MzAyMjE=" # ✓ Funciona base64("answer:43289725") = "YW5zd2VyOjQzMjg5NzI1" # ✓ Formato answer # ERRADO: tipo com maiúscula base64("Question:57830221") = "UXVlc3Rpb246NTc4MzAyMjE=" # ✗ Erro "couldn't parse ID" # JavaScript (browser extension): const encodedId = btoa(`question:${numericId}`); # Python: import base64 encoded_id = base64.b64encode(f"question:{numeric_id}".encode()).decode() # Extraindo ID numérico da URL: # https://brainly.com.br/tarefa/57830221 -> 57830221 const match = url.match(/brainly\.com\.br\/tarefa\/(\d+)/); const numericId = match ? match[1] : null;

Query 1: question(id) — Busca por ID (SEM AUTH)

GraphQL Query
query GetQuestion($id: ID!) { question(id: $id) { id # base64 encoded ID content # HTML da pergunta subject { name } # "Direito", "Matemática", etc. grade { name } # "Ensino superior", "Médio", etc. answers { nodes { id # base64("answer:numericId") content # HTML da resposta rating # pontuação numérica thanksCount # número de agradecimentos author { nick } # username do autor } } } }

⚠ Compatibilidade de clientes HTTP

  • Browser extension (fetch): ✓ Funciona perfeitamente — user-agent e TLS reais do browser
  • curl com user-agent Mozilla: ✓ Funciona — Cloudflare aceita
  • Python requests: ✗ Bloqueado pelo Cloudflare — TLS fingerprint diferente
  • Python httpx/curl-cffi: ✓ Pode funcionar — impersona TLS do Chrome/Firefox
  • Puppeteer/Playwright: ✓ Funciona (browser real)

Workaround: Busca por Texto sem Autenticação

✓ Estratégia recomendada para AnswerHunter

💡 Solução: Serper + question(id)

Como questionSearch requer auth, mas question(id) funciona sem auth, a estratégia é: usar a Serper API (já integrada) para buscar no Brainly via Google, extrair o ID da tarefa da URL e fazer a query GraphQL direta.

1
Serper API — busca site:brainly.com.brQuery: site:brainly.com.br [texto da questão] → retorna lista de URLs
2
Extrair IDs das URLsPattern: /tarefa/(\d+)/ → ex: URL .../tarefa/57830221 → ID 57830221
3
Encode do IDbtoa("question:" + numericId) → "cXVlc3Rpb246NTc4MzAyMjE="
4
Query GraphQLPOST para https://brainly.com.br/graphql/pt com query question(id) — sem headers de auth
5
Processar respostaExtrair answers.nodes[].content, remover HTML, ordenar por rating + thanksCount
6
Integrar ao EvidenceServiceRetornar como evidência com source:"brainly", confidence baseada no rating

Código completo — BrainlyService.js

src/services/search/BrainlyService.js
// BrainlyService.js — Integração com Brainly GraphQL API // Sem autenticação necessária para question(id) export class BrainlyService { static GRAPHQL_URL = 'https://brainly.com.br/graphql/pt'; static TAREFA_URL_RE = /brainly\.com\.br\/tarefa\/(\d+)/; /** Extrai ID numérico de URL do Brainly */ static extractId(url) { const m = url.match(BrainlyService.TAREFA_URL_RE); return m ? m[1] : null; } /** Codifica ID para formato Relay base64: base64("question:"+id) */ static encodeId(numericId) { return btoa(`question:${numericId}`); } /** Busca questão e respostas pelo ID numérico da tarefa */ static async getQuestionById(numericId) { const id = BrainlyService.encodeId(numericId); const res = await fetch(BrainlyService.GRAPHQL_URL, { method: 'POST', headers: { 'content-type': 'application/json; charset=utf-8', 'origin' : 'https://brainly.com.br', 'referer' : `https://brainly.com.br/tarefa/${numericId}`, }, body: JSON.stringify({ operationName: 'GetQuestion', variables: { id }, query: `query GetQuestion($id: ID!) { question(id: $id) { id content subject { name } grade { name } answers { nodes { id content rating thanksCount author { nick } } } } }` }) }); const json = await res.json(); return json?.data?.question ?? null; } /** * Fluxo principal: lista de URLs do Brainly (do Serper) -> respostas * @param {string[]} brainlyUrls URLs retornadas pelo Serper * @returns {Promise<Object[]>} evidências formatadas */ static async getAnswersFromUrls(brainlyUrls) { const results = []; for (const url of brainlyUrls) { const id = BrainlyService.extractId(url); if (!id) continue; try { const question = await BrainlyService.getQuestionById(id); if (!question?.answers?.nodes?.length) continue; // Ordenar por rating + thanksCount const sorted = [...question.answers.nodes] .sort((a, b) => (b.rating + b.thanksCount) - (a.rating + a.thanksCount)); const best = sorted[0]; const strip = html => html.replace(/<[^>]+>/g, '').trim(); results.push({ source : 'brainly', url, questionContent: strip(question.content), answerContent : strip(best.content), rating : best.rating, thanksCount : best.thanksCount, author : best.author?.nick, subject : question.subject?.name, grade : question.grade?.name, allAnswers : question.answers.nodes.map(a => ({ content : strip(a.content), rating : a.rating, thanks : a.thanksCount, author : a.author?.nick, })), }); } catch (e) { console.error(`[BrainlyService] Erro ao buscar ${url}:`, e); } } return results; } }

📌 Limpeza do HTML nas respostas

Os campos content contêm HTML com <br>, <p>, <img> (fórmulas), etc.

Para texto plano: content.replace(/<[^>]+>/g, '') — ou use DOMParser no browser para preservar formatação.

Studocu

✗ Bloqueado por Cloudflare

✗ Status: Cloudflare Browser Challenge (HTTP 403)

Studocu usa Cloudflare com browser integrity check + challenge. Qualquer requisição sem TLS fingerprint de browser real recebe cf-mitigated: challenge.

Método de acessoResultado
curl (qualquer user-agent)HTTP 403 — cf-mitigated: challenge
Python requestsHTTP 403 — bloqueado
Browser real (Firefox/Chrome)HTTP 200 — funciona
URL de buscahttps://www.studocu.com/pt-br/search?q={query}
Conteúdo gratuitoLimitado — maioria requer conta premium

⚠ Recomendação

Studocu não é fonte primária viável para o AnswerHunter sem browser real. Use apenas snippets do Google retornados pelo Serper para contexto adicional.
